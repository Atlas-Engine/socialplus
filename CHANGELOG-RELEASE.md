- Fixed the crossed-swords arena icon appearing in the gap between two rows instead of beside the friend it belongs to. It affected friends shown with the generic WoW logo rather than a faction crest -- that is, any friend on your own WoW version whose realm hasn't resolved yet.
- The generic WoW logo now matches every other row icon in size and sits on the same centre line as them. It was being drawn at roughly twice the size of a faction crest, and cropped from an off-centre part of its texture, which left it sitting high on the row.
- Building the friends list no longer re-scans the entire friend list once for every group. Each friend's group membership is now worked out once per refresh, so that part of the work no longer grows with the number of groups you have.
