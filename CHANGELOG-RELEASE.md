- Friends whose name starts with an accented capital can be found again. Élodie was searchable as "lodie" but not as "elodie" or "élodie", because the first letter was being dropped rather than matched.
- Battle.net friends playing TBC Classic Anniversary now show their arena ratings, and friends playing Mists do too from an Anniversary client. Ratings are looked up on the ladder for the game that friend is actually in, so a name that exists in both never returns the wrong person's rating.
- Fixed the region flag and faction crest occasionally belonging to a different character than the one named beside them, for friends whose game account comes back incomplete.
- Less work per redraw on a large friends list: each WoW friend is now read once a frame instead of several times.
- The player's region is read from the game rather than worked out from a setting, so it is right on clients where that setting is spelled unexpectedly.
